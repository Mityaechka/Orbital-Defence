# Wave Direction Warning Plan

Дата: 2026-09-06

## Цель

Показывать игроку, с какой стороны придет следующая волна или следующая стадия волны. Во время прокачки это помогает осознанно строить и улучшать защиту, а за секунду до новой стадии дает короткий читаемый warning прямо в игровом поле.

## Текущее состояние

- Волна описана через `WaveConfig`.
- Внутри волны есть массив `EnemySpawnGroup`.
- Каждый `EnemySpawnGroup` уже содержит направление спавна: `AngleDegrees` и разброс `AngleSpreadDegrees`.
- Отдельной runtime-сущности `WaveStage` пока нет.
- Сейчас `WaveSystem` последовательно проходит по `SpawnGroups`; для MVP каждый `EnemySpawnGroup` можно считать стадией волны.

## UX

- В фазе `BuildPhase` или `UpgradeChoice` показывать значок `!` на краю игрового поля со стороны первой стадии следующей волны.
- Значок должен быть расположен по направлению `AngleDegrees` относительно центра планеты.
- Если у стадии есть `AngleSpreadDegrees`, можно дополнительно показать короткую дугу/сектор позже, но для MVP достаточно одного `!`.
- При старте волны скрывать предупреждение первой стадии после начала спавна.
- За `1` секунду до следующей стадии внутри активной волны снова показывать `!` со стороны следующего `EnemySpawnGroup`.
- После начала спавна этой стадии скрывать значок.
- После завершения последней стадии и волны значок не показывать до перехода в фазу прокачки/строительства.

## Правила Показа

- Next wave warning:
  показывается между волнами, если существует следующая волна и у нее есть хотя бы одна spawn group.

- Next stage warning:
  показывается во время активной волны за `stageWarningLeadTime = 1f` до начала следующей spawn group.

- Нет данных:
  если следующая волна или стадия отсутствует, warning скрыт.

- Победа/поражение:
  warning всегда скрыт.

## Технический План

### 1. Данные о следующем направлении

Добавить в `WaveSystem` read-only API для UI:

- `bool TryGetNextWaveDirection(out float angleDegrees)`
- `bool TryGetCurrentOrNextStageDirection(out float angleDegrees)`

Для начала достаточно API по следующей волне. Для предупреждения стадий понадобится runtime-событие.

### 2. События волн и стадий

Расширить `WaveSystem` событиями:

- `WavePreviewChanged(float angleDegrees, bool visible)`
- `StageWarningStarted(float angleDegrees)`
- `StageStarted(int waveNumber, int stageIndex)`
- `StageWarningEnded()`

Для MVP можно сделать компактнее:

- `event Action<float> NextDirectionWarningRequested`
- `event Action DirectionWarningHidden`

Главное, чтобы UI не считал тайминги сам, а только отображал команды от `WaveSystem`.

### 3. Тайминг стадий

В `SpawnWave` перед каждой группой после первой:

- показать warning направления следующей группы;
- подождать `stageWarningLeadTime`;
- скрыть warning;
- начать спавн группы.

Для первой группы warning уже показан в фазе прокачки, поэтому при старте волны его нужно скрыть сразу перед спавном.

Важно: если между стадиями позже появится отдельная пауза, warning должен показываться в конце этой паузы, за `1` секунду до спавна.

### 4. UI Indicator

Добавить новый presenter, например `WaveDirectionWarningPresenter`.

Ответственность:

- подписаться на `WaveSystem` и `GameStateController`;
- показывать/скрывать `VisualElement` с `!`;
- переводить world angle в позицию UI;
- держать значок внутри safe зоны экрана;
- сделать короткую анимацию появления/pulse.

Для текущего UI Toolkit:

- элемент `warning-layer` в `GameplayUI.uxml`;
- динамические `Label` с символом `!`;
- absolute position считается от центра root-элемента;
- радиус позиции зависит от размера root, например `min(width, height) * 0.38f`.

### 5. Генерация Сцены

Так как текущая сцена воспроизводимо собирается через `PrototypeSceneBuilder`, добавить создание warning UI туда:

- создать `UIDocument` с `warning-layer` внутри UXML;
- связать его с `WaveSystem`;
- скрыть по умолчанию;
- пересобрать `MainGameplay` через Unity CLI команду `orbital_defense_build_prototype`.

### 6. Локализация

Для MVP текстовая локализация не обязательна, потому что значок `!` универсальный.

Если добавим tooltip/label позже:

- `ui.warning.next_wave`
- `ui.warning.next_stage`

## Критерии Готовности

- В фазе прокачки/строительства видно `!` со стороны, откуда начнется следующая волна.
- При нажатии `Start Wave` warning исчезает перед первым спавном.
- Перед каждой следующей стадией активной волны warning появляется за `1` секунду.
- Warning появляется в правильном направлении для разных `AngleDegrees`.
- Warning скрывается при `Victory` и `Defeat`.
- Unity compile проходит без ошибок.
- `MainGameplay` пересобирается через `orbital_defense_build_prototype`.

## Открытые Решения

- Нужна ли дуга направления при большом `AngleSpreadDegrees`, или оставляем только `!`.
- Должен ли warning быть в screen-space UI или world-space рядом с орбитой.
- Нужно ли показывать тип врага следующей стадии рядом со значком.

## Рекомендация Для MVP

Сделать screen-space `!` без дуги и без текста. Использовать текущие `EnemySpawnGroup` как стадии волны. Это даст понятный игровой сигнал с минимальным риском для существующей системы волн.
