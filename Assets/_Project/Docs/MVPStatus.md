# Orbital Defense MVP Status

Дата обновления: 2026-09-06

## Статус коротко

MVP уже имеет базовый игровой скелет: сцена, планета, две луны, слоты, строительство, экономика, волны, враги, бой, апгрейды, финальные состояния и первый Web playtest build. Сейчас проект находится на стадии playable prototype, но еще требует ручного balance/playtest прохода.

## Ближайший порядок работ

1. Открыть Web build в desktop browser и пройти быстрый smoke-test.
2. Прогнать 10 волн вручную и поправить баланс.
3. Проверить UI на телефоне после первого Web/mobile билда.
4. Выбрать способ шаринга: itch.io, GitHub Pages, Netlify или Vercel.
5. Добавить базовые звуки: выстрел, попадание, сбор ресурса, урон Core.

## Риски

- Баланс волн пока не проверен полноценной сессией.
- UI функциональный, но еще не финально удобный для телефона.
- Визуалы пока placeholder, не финальный стиль.
- Kenney sprites подходят для прототипа, но здания еще могут потребовать отдельные кастомные спрайты.
- Web build собран, но мобильные браузеры могут потребовать оптимизаций.
- Проект пока не инициализирован как git repository.
