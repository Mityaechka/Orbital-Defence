## Acceptance Rules

Механика считается принятой только если:

- игрок понимает направление следующей атаки до запуска волны;
- игрок может осознанно изменить положение каждой луны;
- слоты и здания перемещаются вместе с луной;
- после запуска волны игровые позиции лун не меняются самопроизвольно;
- игрок может отменить ошибочное перемещение до старта волны;
- покрытие пушек обновляется сразу после перемещения луны;
- каждый прорыв врага объясним финальной конфигурацией обороны;
- одна и та же зафиксированная конфигурация дает одинаковое направление атаки;
- управление работает мышью и на touch-экране;
- механика создает минимум две разумные defensive-конфигурации для тестовой волны.
